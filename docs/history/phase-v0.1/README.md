# Phase v0.1 working documents

These files lived at the repository root during the first phase (18–19 Sep 2026). They were moved here on 2026-09-30 without any change to their content. Reports and specifications of that phase cite them by file name only, e.g. `BENCH_01_SPEC.md`. The code that reads one of them was updated: `experiments/bench01/runner.py` and `tests/test_bench_01_protocol.py`.

| File | Content |
|---|---|
| `BENCH_01_SPEC.md` | Locked protocol of benchmark BENCH-01 |
| `M1_SPEC.md`, `M2_SINGLE_STATE_SPEC.md`, `M2_STATE.md` | Milestone specifications and state |
| `PROJECT_STATE.md` | Project state at the end of the phase |
| `KEPT_COMPONENTS.md`, `REMOVED_COMPONENTS.md` | Component decisions |
| `ABLATION_LOG.md`, `FAILURE_LOG.md` | Ablation and failure logs |
| `SESSION_RECONSTRUCTION_NOTE.md` | Note on reconstructing a lost working session |
