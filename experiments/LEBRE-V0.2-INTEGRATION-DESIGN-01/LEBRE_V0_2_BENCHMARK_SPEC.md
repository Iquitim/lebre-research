## 1. Benchmark Suite Overview

The integration diagnostic benchmark suite consists of 14 synthetically generated causal data streams ($I_1$ through $I_{14}$) spanning 6,000 prequential time steps each ($T=6000$, $D=5$ input features). Every benchmark possesses exact mathematical ground truth for evaluation diagnostics, but the learner receives **zero metadata, zero labels, and zero transition cues**.

---

## 2. Mathematical Task Definitions

### I1 — MEMORYLESS_LINEAR (Negative Temporal Control)
- **Generative Process:**  
  $$y_t = w_{\text{true}}^T x_t + \epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, \sigma^2)$$
  with $w_{\text{true}} = [0.8, -0.6, 0.4, -0.3, 0.2]^T$, $\sigma = 0.1$.
- **Expected Ground Truth Class:** `NONE` (Zero temporal capacity).
- **Audit Purpose:** Confirms that unneeded temporal capacity is never allocated when the linear baseline is sufficient.

### I2 — STATIC_NONLINEAR_NEGATIVE_CONTROL (Mandatory Safety Check)
- **Generative Process:**  
  $$u_t = w_{\text{true}}^T x_t, \quad y_t = u_t + 0.35 u_t^2 - 0.15 u_t^3 + \epsilon_t$$
  with zero delayed terms ($x_{t-k}$ absent for all $k \ge 1$).
- **Expected Ground Truth Class:** `NONE` (Zero temporal capacity).
- **Audit Purpose:** **Critical architectural safety test.** Verifies whether approximation error from an inadequate instantaneous linear model triggers false temporal escalation.

### I3 — SINGLE_EXACT_DELAY (Discrete Baseline)
- **Generative Process:**  
  $$y_t = w_{\text{true}}^T x_t + 0.85 x_{1, t-6} + \epsilon_t$$
- **Expected Ground Truth Class:** `LAG_ONLY` (Single tap at $i=1, k=6$).
- **Audit Purpose:** Verifies single-lag discovery, parameter convergence, and absence of spurious recurrent allocation.

### I4 — MULTI_SPARSE_DELAY (Non-Contiguous Transport)
- **Generative Process:**  
  $$y_t = w_{\text{true}}^T x_t + 0.75 x_{0, t-3} - 0.60 x_{2, t-14} + 0.80 x_{4, t-27} + \epsilon_t$$
- **Expected Ground Truth Class:** `LAG_ONLY` (3 non-contiguous taps at lags 3, 14, 27).
- **Audit Purpose:** Verifies that sparse lag selection isolates widely separated delays without contiguous tap bloat or false recurrence.

### I5 — MOVING_DELAY_SUPPORT (Abrupt Support Relocation)
- **Generative Process:**  
  $$y_t = \begin{cases} w_{\text{true}}^T x_t + 0.85 x_{1, t-4} + \epsilon_t, & t < 3000 \\ w_{\text{true}}^T x_t + 0.85 x_{3, t-18} + \epsilon_t, & t \ge 3000 \end{cases}$$
- **Expected Ground Truth Class:** `LAG_ONLY` (Support migration from lag 4 to lag 18).
- **Audit Purpose:** Evaluates obsolescence eviction latency and rediscovery latency under sudden support shifts.

### I6 — CONTINUOUS_LATENT_STATE (Linear Dynamical State-Space)
- **Generative Process:**  
  $$z_t = 0.88 z_{t-1} + 0.40 x_{0, t} + \nu_t, \quad y_t = w_{\text{true}}^T x_t + 0.90 z_t + \epsilon_t$$
- **Expected Ground Truth Class:** `RECURRENT_ONLY` ($N=1$ continuous latent state).
- **Audit Purpose:** Evaluates recurrent candidate promotion and verifies that discrete taps do not falsely over-allocate on smooth exponential memory.

### I7 — QUIESCENT_CONTINUOUS_STATE (Recurrent Silence Test)
- **Generative Process:**  
  Identical to I6, but features $x_t$ are silenced ($x_t = 0$) for $2000 \le t < 4000$.
- **Expected Ground Truth Class:** `RECURRENT_ONLY` (Quiescent retention).
- **Audit Purpose:** Verifies that continuous state parameters and active status survive extended silence.

### I8 — QUIESCENT_DISCRETE_DELAY (Lag Silence Test)
- **Generative Process:**  
  Identical to I3 ($x_{1, t-6}$), with input silence ($x_t = 0$) for $2000 \le t < 4000$.
- **Expected Ground Truth Class:** `LAG_ONLY` (Quiescent retention).
- **Audit Purpose:** Confirms two-timescale obsolescence freeze preserves active discrete taps during silence.

### I9 — HYBRID_DELAY_PLUS_LATENT_STATE (Mandatory Composite Complementarity)
- **Generative Process:**  
  $$z_t = 0.85 z_{t-1} + 0.35 x_{1, t} + \nu_t$$
  $$y_t = w_{\text{true}}^T x_t + 0.70 x_{3, t-12} + 0.80 z_t + \epsilon_t$$
- **Expected Ground Truth Class:** `BOTH` (Lag at $i=3, k=12$ AND Recurrent unit $z_t$).
- **Audit Purpose:** **Mandatory hybrid benchmark.** Proves that when data requires two distinct temporal mechanisms, an oracle with only lag leaves latent error, an oracle with only recurrence leaves delay error, and the joint model achieves superior conditional gain.

### I10 — REDUNDANT_TEMPORAL_STRUCTURE (Arbitration Stress Test)
- **Generative Process:**  
  Target is generated by a first-order autoregressive process driven by input history:
  $$y_t = w_{\text{true}}^T x_t + 0.70 y_{t-1} + 0.40 x_{0, t-1} + \epsilon_t$$
  *Mathematical Property:* Because $y_{t-1}$ is autoregressive, it can be approximated either by a recurrent state ($s_t \approx 0.7 s_{t-1} + \dots$) OR by a truncated finite lag series ($x_{t-1}, x_{t-2}, \dots$).
- **Expected Ground Truth Class:** `LAG_ONLY` OR `RECURRENT_ONLY` (Strictly **NOT** `BOTH`).
- **Audit Purpose:** **Directly tests Invariant VII (No Double Payment).** Evaluates whether the arbitrator prevents redundant dual allocation when one module renders the other predictively obsolete.

### I11 — REGIME_SWITCH_DELAY_TO_LATENT (Structural Migration A)
- **Generative Process:**  
  $$y_t = \begin{cases} w_{\text{true}}^T x_t + 0.80 x_{1, t-8} + \epsilon_t, & t < 3000 \\ w_{\text{true}}^T x_t + 0.90 z_t + \epsilon_t, & t \ge 3000 \quad (z_t = 0.85 z_{t-1} + 0.4 x_{0, t}) \end{cases}$$
- **Expected Ground Truth Class:** Transition from `LAG_ONLY` $\to$ `RECURRENT_ONLY`.
- **Audit Purpose:** Quantifies structural reallocation latency from discrete delay to continuous state.

### I12 — REGIME_SWITCH_LATENT_TO_DELAY (Structural Migration B)
- **Generative Process:**  
  Reversed transition: $t < 3000$ is Continuous Latent State; $t \ge 3000$ is Discrete Lag ($x_{2, t-10}$).
- **Expected Ground Truth Class:** Transition from `RECURRENT_ONLY` $\to$ `LAG_ONLY`.
- **Audit Purpose:** Confirms structural elasticity operates symmetrically in both directions.

### I13 — REGIME_SWITCH_HYBRID_TO_MEMORYLESS (Structural Demotion)
- **Generative Process:**  
  $$y_t = \begin{cases} \text{Hybrid Process (I9)}, & t < 3000 \\ w_{\text{true}}^T x_t + \epsilon_t, & t \ge 3000 \end{cases}$$
- **Expected Ground Truth Class:** Transition from `BOTH` $\to$ `NONE`.
- **Audit Purpose:** Verifies complete retirement of all temporal capacity when dependencies vanish.

### I14 — INTERMITTENT_HYBRID (Temporal Intermittency)
- **Generative Process:**  
  Alternating 1,500-step windows:
  - $0 \le t < 1500$: Discrete Lag ($x_{0, t-5}$)
  - $1500 \le t < 3000$: Continuous State ($z_t$)
  - $3000 \le t < 4500$: Both Active (Hybrid)
  - $4500 \le t < 6000$: Memoryless Linear
- **Expected Ground Truth Class:** `LAG` $\to$ `REC` $\to$ `BOTH` $\to$ `NONE`.
- **Audit Purpose:** Tests continual structural plasticity across repeated environmental transitions.
