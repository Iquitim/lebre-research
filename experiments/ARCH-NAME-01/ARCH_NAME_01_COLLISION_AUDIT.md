## 2. Collision Audit for the 10 Shortlisted Candidates

Each candidate on the active shortlist was evaluated across four conflict dimensions:
- **Academic Literature:** Presence of competing neural network architectures, algorithms, or benchmarks with identical naming.
- **Open-Source Software:** Existing Python packages, PyPI libraries, or prominent GitHub repositories.
- **Commercial & Trademark Identity:** Notable trademarks in Class 09 (computer software) or Class 42 (technology services).
- **Searchability:** Likelihood that a web query for `"<NAME> architecture"` or `"<NAME> machine learning"` identifies the project without drowning in unrelated results.

### Candidate 1: AETAS
- **Academic Literature:** **LOW_COLLISION**. A research group at Beijing Institute of Technology operates as the "AETAS Lab" (publishing on general medical deep learning and SNNs), and one digital humanities pipeline used "AETAS" for historical text drift. Zero machine learning architectures or learning frameworks bear this name.
- **Open-Source Software:** **LOW_COLLISION**. No major PyPI package or GitHub repository exists for an "AETAS" ML framework.
- **Trademark / IP Risk:** **LOW**. Aetas Global Innovation (`aetas.ai`) operates IT services, but no conflicting registered trademark for an adaptive streaming neural architecture was found in preliminary checks.
- **Searchability:** **HIGH**. The query `"AETAS architecture" machine learning` returns minimal noise, making post-publication citation and discovery straightforward.
- **Overall Verdict:** **LOW_COLLISION** — *Nenhum conflito relevante identificado na busca preliminar.*
