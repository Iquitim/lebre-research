# packages/

`lebre/` is a snapshot of the installable library at version 0.1.0 as it was verified against this research record. In the reference environment it reproduces the published predictions bit for bit (`scripts/check_lebre_package.py`).

The library is developed in its own repository: **https://github.com/Iquitim/lebre**, published on PyPI (`pip install lebre`) and archived at doi:10.5281/zenodo.23073983. Use that repository for new versions, issues and releases. This folder stays as the reference of what 0.1.0 implements.
