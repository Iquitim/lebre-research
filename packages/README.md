# packages/

`lebre/` is a snapshot of the installable library at version 0.1.0 as it was verified against this research record. It reproduces the published predictions bit for bit (`scripts/check_lebre_package.py`).

The library is developed in its own repository: **https://github.com/Iquitim/lebre**. Use that repository for new versions, issues and releases. This folder stays as the reference of what 0.1.0 implements.
