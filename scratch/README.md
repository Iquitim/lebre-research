# scratch/

One-off helper scripts from earlier phases: document builders, audits, figure generators and analyses of the v0.1–v0.51 work. Some of them are imported by later builders and analyses, for example `scratch.bench_v02_integration` in the v0.51 specification builder, so the folder stays in place. It is not maintained code; see `REPRODUCIBILITY.md` for the scripts behind the current results. Rendered images are git-ignored.
